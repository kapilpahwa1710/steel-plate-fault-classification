# BITS ML Assignment 2 - submission gate

The ZIP includes a reference implementation. **It is NOT a completed submission
until the real UCI data is processed on BITS Virtual Lab and the user supplies
external URLs, runs the deployed app, and captures one authentic lab screenshot.**

## Required hands-on actions

1. Use BITS Virtual Lab, not your regular personal computer, for the evaluated experiment.
2. Download original Steel Plates Faults data from UCI if automatic fetching fails.
3. Install requirements and run `python train_models.py` (or use `--data-path`).
4. Keep the exact files generated by that command: `test_data.csv`, `model/*.joblib`,
   `model_comparison.csv`, `model_metadata.json`, `data/steel_plates_prepared.csv`.
5. Review the confusion matrices and model-specific errors in the Streamlit app.
6. Explain your own modelling choices (e.g. stratification, scaling, class imbalance,
   and why your chosen winner scored best on macro-F1).
7. Make an original UI / documentation refinement; the handout warns against
   cloned templates and direct AI copy-paste.
8. Create and populate a real GitHub repository with all required files, including
   `README.md` and `test_data.csv`; preserve meaningful incremental commit history.
9. Deploy the repository on Streamlit Community Cloud, then click the public URL and
   actually upload `test_data.csv` to verify the model scores.
10. Take **one real screenshot** of training/execution on BITS Virtual Lab; never
    substitute a locally generated image.
11. Update README with correct repository and app URLs by running `build_readme.py`.
12. Install optional PDF generation dependencies via `python -m pip install -r requirements-report.txt` and build one final PDF with `build_submission.py` and verify links, embedded screenshot,
    README content, and required ordering.
13. Run `python verify_submission.py` for a technical preflight (does not establish
    externally hosted link availability).

## Rubric coverage

- Dataset: UCI source, 1,941 observations, 27 features, seven classes.
- Classifiers: Logistic Regression, Decision Tree, KNN, Gaussian Naive Bayes, SVM.
- All six metrics per model: Accuracy, macro OvR AUC, macro Precision, macro
  Recall, macro F1, multiclass MCC.
- README structure: (a) problem, (b) dataset description, (c) GitHub link,
  (d) table of five models and observations plus winner, (e) deployment notes.
- Streamlit: test CSV upload, model dropdown, current metrics, confusion matrix
  and per-class classification report; no retraining; all five visible.
- Submission PDF order: 1 GitHub link, 2 public Streamlit link, 3 one authentic
  BITS Virtual Lab screenshot, 4 full README content.

**Do not submit `submission_DRAFT.pdf`**, which deliberately marks missing evidence.
